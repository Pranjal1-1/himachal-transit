# 04 — Bus / Route / Stop Management

Bus fields:
registration number, model, capacity, fuel type, emission standard, organization, status.

Route fields:
name, origin, destination, geometry, ordered stops.

Stop fields:
name, latitude, longitude, address.

Organization assigns driver → bus → trip/route.

Sustainability information is verified organization data:
Diesel / CNG / Electric / Hybrid and BS-III / BS-IV / BS-VI / Electric / Unknown.
