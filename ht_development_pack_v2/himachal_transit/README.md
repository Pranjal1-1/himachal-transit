# Himachal Transit (monorepo)

This folder contains the Phase 01 development scaffolding for the Himachal Transit app.

Structure:

- mobile/       — Flutter app (single codebase for Passenger & Driver)
- backend/      — Node.js + TypeScript backend
- admin/        — Admin dashboard (Next.js scaffold)
- docs/         — Design and developer docs
- reference_ui/ — UI reference images and assets

Phase 01 scope: scaffold projects and basic runnable backend health check. Do not implement later phases yet.
