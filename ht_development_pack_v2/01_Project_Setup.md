# 01 — Project Setup

Create:
```text
himachal_transit/
  mobile/       # Flutter
  backend/      # Node.js + TypeScript
  admin/        # Next.js/React
  docs/
  reference_ui/
```

Install Flutter/Dart support in VS Code. Install Android Studio for the Android SDK/emulator.

Initialize Git. Keep secrets out of Git. Use .env.example.

Done when Flutter, backend and admin can each start locally.
