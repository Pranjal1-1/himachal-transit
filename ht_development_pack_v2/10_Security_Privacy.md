# 10 — Security & Privacy

Use OWASP MASVS principles for mobile security and OWASP API Security principles for the backend.

Implement:
- HTTPS/TLS
- strong password hashing
- secure token storage
- backend authorization
- rate limiting
- input validation
- audit logs
- private database
- admin protection
- privacy controls

GPS validation:
- authenticated driver
- authorized bus
- active trip
- valid timestamp
- plausible speed
- plausible location movement
- reject unauthorized or stale updates

Privacy:
- explain passenger location use
- avoid unnecessary passenger background tracking
- driver tracking primarily during active trips
- stop driver tracking after trip ends
- define retention policies
