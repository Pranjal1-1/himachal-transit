# 07 — Passenger App

Use the supplied Passenger Home/Bus Discovery and Passenger Tracking/Journey images as the UI reference.

Screens:
- Home
- Search
- Search Results
- Nearby Buses
- Live Map
- Bus Details
- Route Details
- Stop Details
- Saved Routes
- Favourite Buses
- Notifications
- Profile
- Privacy & Security
- Help

Design direction:
modern transit app, purple/indigo accent, white cards, rounded components, clean typography, map-first tracking, strong ETA/status hierarchy.

Bus Details:
live status, location, next stop, ETA, speed, distance, traffic when available, route, fuel, emission standard.
